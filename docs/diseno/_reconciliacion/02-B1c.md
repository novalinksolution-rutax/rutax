El **seller va último**, dentro de «Facturación» (`:299-341`); el tablero lo pone **primero**, como `DE QUIÉN ES`. - **La comuna es un `input` de texto libre** (`:231-240`), no una lista. El catálogo existe y está a mano — `COMUNAS_RM` en `src/lib/ui/comunas-rm.ts:2` — pero el formulario no lo usa. El copy del tablero («Elige una comuna de la lista») **no se puede cumplir hoy**.
- **No hay validación de teléfono**: el campo es `type="tel"` sin regla (`:252-258`). `validar()` (`:47-62`) solo comprueba tres obligatorios, y **corre al enviar**, no al salir del campo.
- **No hay ayuda bajo ningún campo.** Lo único parecido es un párrafo gris arriba de todo: «Este pedido se agrega al panel y queda disponible para asignarlo a un manifiesto.» (`:172-174`).

- **Sin tarifa: hoy es un error, no un aviso previo.** `crearPedidoSameDay` lanza `ErrorValidacion` si el seller no tiene tarifa vigente (`pedidos.ts:1122-1134`) y el pedido **no se crea**; el mensaje llega después de enviar, como error de servidor (`:176-180`).
